# Old money

桃园集团 · 三国现代财阀纪实摄影 Skill 1.0

> 先像照片，再像作品。
>
> 先模拟一个真实摄影师进入一个真实存在的三国现代财阀世界，再决定怎么拍。

把三国人物重构为现代东方家族控股集团成员，并为他们设计具有真实拍摄逻辑的影像：私人晚宴快照、集团年鉴、产业现场记录、旧杂志人物摄影与家族档案。

本项目提供可复用的文字技能和提示词示例，不包含生图服务、模型、API 或参考图片。人物与现代集团设定属于虚构创作。

## 设计理念

“老钱感”来自已经成立的人物身份、空间归属与摄影现场。财富有港口、矿业、制造、能源和物流等实体来源；房间有长期使用痕迹；人物有正在进行的事情；摄影师有进入现场的理由和明确的位置。

视觉母体由 90 年代纪实奢华摄影、财阀家族档案、私人宴会快照、工业资本、东方门阀、编辑部人物摄影和真实胶片扫描质感共同构成。

最高规则：**摄影师记录一个本来就存在的世界。**

## 核心原则

- **真实性优先**：允许褶皱、毛孔、曝光偏差、前景遮挡与运动模糊；避免完美无瑕的 AI 海报感。
- **空间说明财富**：用长期占有和使用的空间、产业与物件说明身份，避免奢侈品堆砌。
- **角色有现代职能**：保留三国人物的精神内核，通过关系、行为、产业和收藏隐藏叙事，避免古装符号拼贴。
- **摄影位置明确**：确定摄影师的位置、距离、相机高度、焦段以及人物对摄影师的反应。
- **环境可阅读**：以 35mm 为核心，按场景选用 28mm 或 50mm；默认中等景深。
- **光线有现场来源**：使用窗光、机顶直闪、工业灯或办公室混合照明，保留真实色温差异。
- **女性具有自主性**：先确定家族身份、掌握的资源和决策位置，再设计外观。

## 使用方式

### 作为通用提示词技能

1. 将 [SKILL.md](SKILL.md) 的正文交给你使用的 AI 助手，要求按照这套摄影规则工作。
2. 给出角色与场景，例如：`孙尚香在集团宴会上。`
3. 获取一段自然、完整的生图提示词，再交给你选择的图像模型。

可以补充年代、画幅、动作或正式合影要求。没有额外要求时，技能默认直接给出一份完整提示词，不展开大量理论，不列出重复版本。

### 在支持 SKILL.md 的助手中使用

将整个仓库文件夹作为一个技能目录，按所用助手的技能加载方式添加；保留 `SKILL.md` 和 `examples/` 的相对位置。技能名称为 **Old money**，技能标识为 `old-money`。不同助手的安装目录和调用语法以各自说明为准。

本技能不绑定特定图像模型；焦段、胶片和曝光等描述用于表达视觉意图，生成结果仍需人工检查。

## 示例

输入：

> 孙尚香在集团宴会上。

输出方向：

> 1998 年的私人宴会纪实照片。吴氏航运家族核心成员孙尚香在老宅通向露台的门边听港口负责人汇报，手指停在折起的泊位计划上；她穿有自然折痕的深色丝绸晚装，刚意识到摄影师便侧过脸。受邀记录晚宴的摄影师站在门内约两米处，以眼平机位、35mm 镜头和机顶直闪拍摄，前景被经过的宾客肩膀遮住一角。室内钨丝壁灯与露台冷色夜光并存，背景暗一至两档，仍能辨认旧航线图、家族船厂合照与正在交谈的宾客。中等景深，ISO 800 彩色负片扫描感，保留皮肤油光、细碎发丝、丝绸反光和暗部颗粒，避免磨皮、品牌堆砌、武将服装和英雄式摆拍。

更多完整示例见 [examples/README.md](examples/README.md)：孙尚香晚宴、刘备办公室、张飞矿场夜班、诸葛亮深夜会议、五人正式家族合影。

示例为开源整理时依据 Skill 1.0 新写的文字演示，尚未作为生图效果基准验证；它们不是原对话参考图片的复刻。
