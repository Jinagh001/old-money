# Skill 1.0 提示词示例

以下为依据定稿新增的完整输出示例，未经过生图验证。默认输出为自然连续描述；角色名字之外，也应能从产业、空间和行为读出身份。

## 孙尚香：私人宴会

输入：`孙尚香在集团宴会上。`

1998 年的私人宴会纪实照片，吴氏航运家族在使用多年的老宅招待合作伙伴，孙尚香作为参与港口业务决策的家族成员，站在通往露台的门边听一位负责人汇报，指尖停在折起的泊位计划上，听见相机响动时侧过脸。深色丝绸晚装腰部有坐过的折痕，耳边有少量碎发，旧腕表没有刻意展示。受邀记录晚宴的摄影师站在门内约两米处，眼平机位、35mm 镜头，中等景深，一位经过的宾客肩膀切入左下角。机顶直闪照亮面孔和丝绸，室内钨丝壁灯与露台冷色夜光并存，背景暗一至两档，旧航线图、家族船厂合照、磨损地毯与远处交谈的人仍可辨认。ISO 800 彩色负片扫描感，保留皮肤油光、玻璃轻微过曝和暗部颗粒。她对家族产业的熟悉和对谈话的主导显出独立性，避免红毯姿势、武将服装、磨皮、品牌堆砌和统一黑金调色。

## 刘备：办公室会客

输入：`刘备在办公室。`

90 年代末集团年鉴摄影师记录的一次会客，桃园集团董事长刘备在老总部办公室听一位地方物流合伙人说明情况，身体稍向对方倾斜，右手停在翻开的运输合同旁，没有看相机。他穿肩线略宽的灰褐色羊毛西装，衬衫肘部有细小褶皱。摄影师获准随会记录，站在办公桌侧后方距刘备约三米的位置，以胸口高度的 35mm 镜头拍摄，前景保留来访者的半边肩膀和打开的公文包。阴天大窗户照亮刘备靠窗的一侧面孔，另一侧自然落暗，无闪光和轮廓补光。中等景深下仍看得见起皱的皮沙发、翻旧的集团名录、墙上的物流线路图，以及书架边一张三位年轻人在桃树下的旧合照。秘书在门边接过文件，动作轻微模糊。ISO 400 彩色负片扫描，肤色有局部差异，木头和旧皮革保留使用痕迹，画面略偏离水平，不做标准董事长宣传照，不用极浅景深和 HDR。

## 张飞：矿场夜班

输入：`张飞在矿场。`

1997 年矿业分公司夜班交接的现场纪实照片，桃园集团实业负责人张飞在矿场调度室外的有顶工作台旁，一手拿着吃到一半的馒头，一手压着工程师刚摊开的设备检修记录，眉头收紧，看向记录中的一行，没有意识到随行内刊摄影师正拍照。他穿旧厚呢外套、工作裤和有泥痕的靴子，外套敞开处能看见反光工作背心，安全帽边沿有擦痕。摄影师站在工作台另一端约两米半处，以胸口高度的 28mm 镜头拍摄；前景是半截搪瓷杯和卷起的矿区图，背景的装载设备与交班工人保持可辨认。顶棚工程灯照亮纸面和面部，远处钠灯偏橙，车辆灯光掠过地面，不加闪光或人为轮廓灯。ISO 800 高感彩色负片，暗部有颗粒，车灯局部溢出，皮肤粗糙、衣料起毛，画面捕捉到工人转身造成的轻微模糊。重资产现场和工程师对他的直接汇报说明他的职能，避免金链、夸张凶狠表情、英雄低机位和整齐的广告布景。

## 诸葛亮：深夜会议

输入：`诸葛亮深夜看并购方案。`

90 年代末的一张集团内部会议记录照片，首席战略官诸葛亮在老总部小会议室翻到并购方案的某页停住，用铅笔指给财务负责人看，身旁摊着港口吞吐量表和产业地图。他穿深灰软肩西装，领带略松，眼下有疲惫阴影，注意力始终停在文件上。获准记录工作过程的摄影师坐在桌角约两米外，以坐姿眼平高度的 50mm 镜头拍摄，不使用闪光，保持足以读出空间关系的中等景深。前景被一叠散开的资料挡住一小块，旧桌灯的暖光落在手与纸上，偏绿的顶灯留在背景，CRT 显示器发出微弱冷光，色温没有完全校正。玻璃隔断后有人边走边接电话，会议桌边缘磨损，杯底留下水印。ISO 800 彩色负片扫描感，暗部颗粒增加，面孔和衣料保持自然纹理。产业地图和信息交汇呈现运筹帷幄，不加入羽扇、发光沙盘、电影轮廓光或全画面锐化。

## 五人：正式家族合影

输入：`给刘备、关羽、张飞、诸葛亮、赵云拍一张正式家族合影。`

1998 年桃园集团周年晚宴开始前的正式家族档案合影，受家族委托的摄影师在老宅主厅距众人约四米处，以约一米四的相机高度和 35mm 镜头拍摄。五人知道摄影师在场，刘备坐在旧皮沙发中间，温和地看向镜头；关羽在右后方站定，张飞坐在左侧独立扶手椅上，诸葛亮站在沙发侧后方，赵云在最靠近门口的一侧收住脚步。服装分别是灰褐羊毛西装、深色长外套、厚呢夹克配西裤、深灰软肩西装和深蓝单排扣西装，衣料都有自然折痕，不用角色代表色编码。五人的间距由家具与关系决定，整体稳定但没有镜像对称；画面下沿保留茶几边缘，背后能读出老相框、集团港口合照、地毯磨损和多年积累的藏书。机顶直闪结合厅内钨丝灯，背景暗一档，眼神朝向不必完全一致，皮肤有真实油光，沙发扶手有闪光反射。中等景深、ISO 400 彩色负片扫描质感，细密颗粒和轻微高光溢出。保留正式合影的安排感与人的小差异，避免英雄海报姿势、磨皮、logo 堆砌和酒店样板间质感。

这里按用户明确要求采用正式合影，对应正文“构图原则”的例外；它不改变其他场景以真实行为和抓拍为主的默认方式。
